# shamzehe.github.io

Source of Samira Hamzehei's personal website: **https://shamzehe.github.io**

Content lives in plain text files, so updating the site doesn't require any coding. Every change
to the `main` branch rebuilds and republishes the site automatically. It's live about 1–2 minutes later.

## Where things are

| To change… | Edit this file |
|---|---|
| Name, headline, bio, links, languages, "What I work on" cards | `data/profile.yaml` |
| News on the home page | `data/news.yaml` |
| Skills & tools | `data/skills.yaml` |
| A research or technical project | `data/projects/<project-name>.yaml` |
| Page titles and intros | `content/<page>/_index.md` |
| Résumé / CV PDFs | upload to `static/files/` (names must match `documents` in `profile.yaml`) |
| Photo | `assets/images/samira-hamzehei.jpg` |

Each data file starts with a short comment that shows the format and an example.

## Editing on github.com

1. Open the file on GitHub and click the **pencil icon** (Edit).
2. Make your change. Copy an existing entry and edit the copy, keeping the same indentation.
3. Click **Commit changes**.
4. Open the **Actions** tab. A green check means the update is live. A red ✗ means something
   in the file needs fixing: click the run to see a plain-English message such as
   `data/news.yaml item 3: missing date`. While it's red, the previous version of the site stays online.

To replace a PDF: open `static/files/`, choose **Add file → Upload files**, and upload a file with the same name.

## Formatting rules for the data files

- Put text in double quotes: `title: "My talk"`.
- Indent with **two spaces**, never tabs.
- IPA is fine as-is: `ipa: "sæ.mi.ˈɾɒ"` (use ˈ and ː, not ' and :).
- Dates: `2026-04-11`, `2026-04`, or `2026`.

## Previewing locally (optional)

With [Hugo](https://gohugo.io) 0.168.0 installed:

```sh
hugo server          # then open http://localhost:1313
python3 scripts/check_links.py public   # after `hugo build`, checks internal links
```

The home-page waveform is generated by `scripts/make_waveform.py`.
